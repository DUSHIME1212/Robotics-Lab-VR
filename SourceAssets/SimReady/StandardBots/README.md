# Standard Bots Thor: SimReady USD

The Standard Bots Thor robot arm as a NVIDIA SimReady USD package for Isaac Sim. It is validated and stamped against the Robot-Body-Runnable 1.1.0 profile.

| Folder | Package | Root USD |
|---|---|---|
| `standardbots_thor/` | `simready.hf.standardbots.simready-thor.standardbots_thor` | `thor/standardbots_thor.usd` |

Each package folder's `com.nvidia.simready.packaging.json` names the version and declares every file with its SHA-256.
